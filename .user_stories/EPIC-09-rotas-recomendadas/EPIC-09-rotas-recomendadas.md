# EPIC-09 — Rotas recomendadas

**Objetivo:** listar coleções curadas com informação suficiente para escolher sem abrir o detalhe.

**Estimativa:** 5 pts · **Telas:** 08 Rotas recomendadas · **Depende de:** EPIC-07

## Histórias

### 09.1 — Lista de coleções
Como utilizador, quero explorar seleções de rotas por tema ou autor.

- RouteCard com título, subtítulo, duração, distância, nº de paragens e etiqueta de coleção

**Aceitação:** lista paginada (20 por página) com scroll infinito e pull-to-refresh.

### 09.2 — Recentemente recomendadas
Como utilizador recorrente, quero ver o que é novo.

**Aceitação:** ordenação por data de curadoria; badge "Novo" até 7 dias.

### 09.3 — Rotas Premium na lista
Como utilizador free, quero ver o que existe em Premium sem ser enganado.

- Cartão com etiqueta discreta; toque abre o detalhe com CTA de upgrade (EPIC-19)

**Aceitação:** nenhuma rota Premium inicia sem subscrição; a etiqueta é visível antes do toque.
