# 01.11 — Cliente HTTP, mocks e datas

Como dev, quero um cliente HTTP e mocks locais previsíveis, para desenvolver sem depender do
backend estar sempre disponível.

## Passos

- [ ] Instalar Axios; instância única com interceptors de auth e erro em `src/lib/http.ts`
      (nunca `fetch` direto em features).
- [ ] Instalar `mockoon-cli` (o environment `tooling/mockoon/waytale.json` já existe, com 2 rotas
      placeholder — `mockoon-cli` ainda não está instalado, o script `pnpm mockoon` na raiz
      falhará até lá).
- [ ] Instalar `date-fns`; toda a manipulação/formatação de datas centralizada em
      `src/lib/date.ts`.

## Aceitação

- [ ] A app corre contra o Mockoon só trocando uma env var, sem tocar em código de produção.
- [ ] Nenhuma função de data usa `Date`/`Intl` diretamente fora de `src/lib/date.ts`.

## Dependências

- 01.1 (bootstrap).
- Independente das restantes; útil ter pronto antes de 01.5 (Supabase) para já haver mocks
  enquanto o backend real não existe.
