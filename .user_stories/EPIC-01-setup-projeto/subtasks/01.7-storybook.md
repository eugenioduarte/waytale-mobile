# 01.7 — Storybook

Como designer, quero ver os componentes isolados, para validar o design system sem correr a app.

## Passos

- [ ] Instalar Storybook RN no dev client de `apps/mobile` (ou em `packages/ui`, a decidir — ver
      nota de dependência abaixo).
- [ ] Build web do Storybook publicado em preview por PR.
- [ ] Decorators com tokens, safe-area e mocks de store.

## Aceitação

- [ ] PR que toca um componente publica link de preview.

## Dependências

- 01.1 (bootstrap).
- Faz mais sentido montar isto depois de `packages/ui` ter pelo menos um componente real
  (EPIC-02), senão o Storybook fica vazio. Pode adiantar-se a configuração base sem esperar por
  EPIC-02, mas o critério de aceitação ("PR que toca um componente publica preview") só é
  verificável quando existir um componente.
