## Limites explícitos

Maestro cobre os fluxos provisórios de navegação, sessão de demonstração e onboarding.
Os testes Jest usam o Mockoon partilhado para integração de rede. OTP real e Maestro contra
backend ficam no EPIC-04, quando existirem os formulários de autenticação.

PRs de forks e do Dependabot não recebem secrets. Os jobs que precisam deles falham com mensagem
explícita; para validação completa, um maintainer deve revisar e transportar a alteração para
um branch confiável do próprio repositório. Não se usa `pull_request_target` para executar código
de PR com credenciais.

O workflow não considera ausência de credenciais um sucesso. O épico mantém pendências externas
abertas até haver evidência, conforme `../CHECKLIST.md`.
