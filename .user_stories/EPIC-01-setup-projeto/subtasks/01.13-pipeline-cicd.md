# 01.13 — Pipeline CI/CD

Como equipa, quero um pipeline que bloqueia merges quebrados e distribui builds sem passos
manuais.

## Passos

- [ ] Workflow GitHub Actions (CI, em PR): lint → typecheck → testes unitários/integração
      (bloqueante) → SonarQube → Dependabot.
- [ ] EAS Build + EAS Submit (CD): build automático ao mergear em `main`; distribuição **apenas
      Android** por agora.
- [ ] Decidir internal track vs. EAS Update para a distribuição Android (em aberto, ver
      EPIC-20).
- [ ] Ligar o `required_status_checks` ao branch protection de `main` — já está configurado
      (`enforce_admins: true`, PR obrigatório) mas sem check obrigatório porque não havia CI
      ainda.

## Aceitação

- [ ] Um PR com teste a falhar não pode ser mergeado.
- [ ] Merge em `main` dispara build EAS e disponibiliza o artefacto Android sem passo manual.

## Dependências

- 01.1 (bootstrap).
- 01.8 (testes) — precisa de testes reais para o CI ter algo bloqueante para correr; sem eles o
  "lint → typecheck → testes" fica incompleto.
