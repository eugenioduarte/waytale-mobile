# 01.2 — Navegação com expo-router

Como dev, quero rotas por ficheiro com grupos de layout, para mapear os fluxos do design 1:1.

## Passos

- [x] Grupos de layout: `(auth)`, `(onboarding)`, `(tabs)`, `(journey)` e modais (`(modals)`).
- [x] Guarda de sessão no layout raiz: sem sessão → `(auth)`; sessão sem onboarding → `(onboarding)`;
      caso contrário → `(tabs)` (+ `(journey)` e `(modals)`). Estado provisório em
      `src/features/auth/session.tsx` (contrato `isAuthenticated` + `hasCompletedOnboarding`).
- [x] Deep links: `waytale://route/:id` (e `place/:id`) resolvem via `(modals)/route/[id]` e
      `(modals)/place/[id]`. O `scheme: "waytale"` já estava em `app.json`; o expo-router deriva os
      padrões dos ficheiros (sem `linking.prefixes` manual como em React Navigation puro).

## Aceitação

- [ ] Navegação profunda restaura o ecrã correto após cold start — o padrão `/route/:id` está
      resolvido (bundle iOS/Android/Web + 34 rotas estáticas), mas a restauração para um
      utilizador **já autenticado** depende da persistência da sessão (01.3). Hoje o cold start é
      sempre anónimo, pelo que o deep link aterrissa corretamente no `(auth)`.
- [x] Voltar do OTP não reentra em estado inválido — garantido por desenho: `signIn()` (em
      `(auth)/verify`) faz a guarda desmontar o grupo `(auth)`, logo o `back` a partir de
      `(onboarding)` não tem OTP para onde voltar. Validação estática (bundle + typecheck); falta
      confirmar o gesto num simulador/dispositivo.

## Dependências

- 01.1 (bootstrap) — estrutura de pastas e `src/app/` já configurados.
- A guarda antecipa 01.5 (Supabase/auth) e 01.3 (sessionStore): o estado provisório
  (`features/auth/session.tsx`) mantém o contrato estável dos grupos para não remapear rotas
  depois. A aceitação do deep link "já autenticado" fica pendente da persistência (01.3).

## Notas

- `(onboarding)` usa ecrãs com nomes próprios (`interests`, `deviations`, `voice`, `permissions`)
  em vez de `index` para não colidir com o `/` de `(tabs)/index`.
- Os ecrãs são placeholders (`components/screen.tsx` + copy em `locales/pt.json`) — o design
  (29 ecrãs) ainda não foi importado, ver `agentic.md` › Design source.
- `.expo/types/router.d.ts` (typed routes) é gerado pelo `expo start` (não pelo `expo export`) —
  regenerar depois de adicionar/renomear rotas antes de `typecheck`.
