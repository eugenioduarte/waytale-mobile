# 01.4 — SQLite local como fonte de verdade

Como utilizador, quero que a app funcione sem rede, porque ando na rua e no estrangeiro.

## Passos

- [ ] Instalar `expo-sqlite` + Drizzle ORM.
- [ ] Tabelas: `routes`, `stops`, `stories`, `story_audio`, `places`, `saved_items`, `journeys`,
      `journey_events`, `downloads`, `outbox`, `meta`.
- [ ] Migrações Drizzle versionadas.
- [ ] Seed de demonstração para dev e Storybook.
- [ ] Garantir que toda a leitura da UI vem do SQLite — a rede só alimenta o SQLite, nunca a UI
      lê diretamente de uma resposta de rede.

## Aceitação

- [ ] Em modo avião, Home, rotas descarregadas, guardados e player funcionam sem ecrã de erro.

## Dependências

- 01.1 (bootstrap) — precisa de `src/db/`.
- O schema das tabelas de utilizador (`saved_items`, `journeys`, `journey_events`, `outbox`) deve
  ficar alinhado com as tabelas Postgres de 01.5, já que 01.6 (sync) vai espelhar campos entre as
  duas.
