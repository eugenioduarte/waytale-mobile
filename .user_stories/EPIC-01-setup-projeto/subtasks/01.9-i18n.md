# 01.9 — Internacionalização (i18n)

Como utilizador, quero a app e a narração no meu idioma, porque viajo em cidades onde não falo a
língua local.

## Passos

- [ ] Instalar `i18next` + `react-i18next` + `expo-localization`.
- [ ] Deteção do idioma do dispositivo, com override manual em Perfil.
- [ ] Estrutura `apps/mobile/src/i18n/<locale>.json`; chaves por feature.
- [ ] Idiomas de lançamento: pt e en (mínimo).
- [ ] Regra de lint que falhe se detetar string de UI fora do i18n.

## Aceitação

- [ ] Mudar o idioma do dispositivo reflete-se na interface sem reiniciar a app.
- [ ] Lint falha se detetar string de UI fora do i18n.

## Dependências

- 01.1 (bootstrap) — precisa de `src/i18n/`.
- Independente das restantes subtasks do épico; pode avançar em paralelo com 01.2–01.6.
