# 01.12 — Firebase: Crashlytics, Push, Analytics

Como equipa, quero crashes, notificações e analytics de produto desde o dia 1, para não navegar
às cegas em produção.

## Passos

- [ ] Criar o projeto Firebase do Waytale (Android — ver nota de escopo em
      `.agents_local/stack.md`, distribuição é Android-only no MVP).
- [ ] Instalar `@react-native-firebase/app` + `crashlytics` + `messaging` + `analytics`.
- [ ] Confirmar dev client (não Expo Go) — já assumido nos Riscos do épico por causa de
      áudio/localização em background; Firebase reforça a mesma exigência.
- [ ] Registar token FCM no Supabase por utilizador (depende de 01.5).
- [ ] Eventos mínimos de analytics: `route_started`, `story_played`, `journey_completed`,
      `place_saved`.

## Aceitação

- [ ] Um crash forçado em dev aparece no Crashlytics em minutos.
- [ ] Um evento de analytics fica visível no dashboard Firebase.
- [ ] Uma notificação de teste chega ao dispositivo.

## Dependências

- 01.1 (bootstrap).
- 01.5 (Supabase) — o registo do token FCM por utilizador precisa da tabela/auth de utilizador já
  existir.
