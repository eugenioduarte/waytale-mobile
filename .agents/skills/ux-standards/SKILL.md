# UX Standards

- Define applicable loading, error, empty, disabled, offline, success, and retry states.
- Use existing tokens and components before adding variants.
- Preserve safe areas, keyboard access, focus, readable contrast, touch targets, and feedback.
- Prefer accessible roles, labels, hints, values, and stable automation identifiers.
- Check small screens, text expansion, and both platforms when material.
- Verify the running UI when approved tooling is available; report when it is not.
