# SDD Creation

1. Read relevant product context, stack, adjacent SDDs, and code.
2. Start from `assets/sdd-template.md` for a new SDD.
3. Record facts, assumptions, decisions, alternatives, and unresolved questions separately.
4. Specify scope, exclusions, flows, states, contracts, migrations, rollout, rollback, verification, acceptance, and risks.
5. Ensure each implementation phase has an observable completion criterion.
6. Store the final document in `.agents_local/sdd/`.
